분석 로그 / 설정 확인

External Signal / Input-short Validation

현재 파일 또는 최근 수신 데이터의 원본을 분석합니다. 필터·offset 보정은 적용하지 않습니다. 발생기 설정값과 실제 입력 실측값은 구분해서 입력하세요.

분석 대기

사인파: 실제 t_us 기반 sine+cosine+DC 최소제곱 피팅(목표 주파수 ±20%, 최소 3주기). PSD: nominal SPS, Hann, 50% overlap, 최대 1024 samples, 구간별 DC 제거, one-sided µV²/Hz. 불규칙 수신 간격이 있으면 PSD 주파수/밀도는 근사값입니다. Input-short는 칩 내부 잡음 시험이며 전극 접촉이나 생체 EEG 품질 검사가 아닙니다.
